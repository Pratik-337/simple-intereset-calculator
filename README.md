# Simple Interest Calculator

This repository contains a basic script to calculate simple interest based on principal, interest rate, and time.

## Formula
`Simple Interest = (P * R * T) / 100`

## Parameters
- **P (Principal)**: The initial amount of money.
- **R (Rate)**: The annual percentage interest rate.
- **T (Time)**: The time period in years.
